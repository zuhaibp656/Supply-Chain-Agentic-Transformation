SLIDE 05 · ARCHITECTURAL FINOPS & RESOURCE REUSE ENGINEERING

How Our Architecture Cuts Cloud Spend by 62.4% at Scale

Naive multi-agent deployments create duplicate Reasoning Engine containers, scan unpartitioned tables on every turn, and ask LLMs to perform arithmetic in tokens. Our repository implements 6 concrete resource-reuse mechanisms out of the box.

Lever 01 · Compute Reuse (-62% Runtime)

In-Place Reasoning Engine & Registration Reuse

scripts/deploy_to_gemini_enterprise.py tracks .reasoning_engine_id and matches existing provisionedReasoningEngine paths via PATCH updates. Renamed catalog counterparts share existing Reasoning Engine IDs rather than spinning up duplicate warm containers.

Lever 02 · Token Offload (-71% Output Tokens)

Deterministic Python & OR-Tools Math Offload

Instead of using expensive Chain-of-Thought tokens to solve MILP scheduling, 3D pallet bin-packing, or CVRPTW routing, each agent calls deterministic Python tools in app/tools.py and only passes the optimal pareto summary back to the LLM.

Lever 03 · Query Cost (-78% BigQuery Bytes)

Shared 245-Table Partitioned Digital Twin

All 60 agents share a single canonical BigQuery dataset (supply_chain_twin) partitioned by date and clustered by (sku_id, facility_id, vendor_id), with local JSON fixture fallback (DEMO_DATA_MODE=fixture) for zero-cost CI/CD and demos.

Lever 04 · Prompt Caching (-75% Input Cost)

Vertex AI Context Caching on Static Schemas

Category instructions, SCOR DS taxonomy rules, and the 4 tool declarations per agent remain invariant across invocations—qualifying for Vertex AI Context Caching at a 75% input token discount.

Lever 05 · Payload Density (-68% Bandwidth)

Visual-First A2UI v0.9 Card Rendering

app/render/surfaces.py emits a single compact VegaChart A2UI card plus atomic copy-ready Markdown tables—eliminating multi-page conversational fluff and cutting average output tokens to ~650.

Lever 06 · Overnight Batch (-50% Batch Rate)

Vertex AI Batch Prediction for Nightly Runs

Nightly MEIO safety stock recalculations, SLOB disposition sweeps, and Scope 3 carbon ledger rollups run via Vertex AI Batch API at a 50% discount compared to synchronous online inference.
